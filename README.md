# 糖尿病饮食健康助手 (Diabetes Diet Assistant)

## 💡 项目简介
这是一个正在开发中的课程设计项目，旨在帮助糖尿病患者科学管理日常饮食。通过智能分析与个性化建议，解决“不知道能吃什么、怎么吃”的痛点。

## 🎯 核心功能
- **食物升糖指数查询**：快速查询常见食物的GI值，避免饮食雷区。
- **个性化食谱推荐**：根据用户的血糖目标和口味偏好，生成一日三餐建议。
- **饮食记录与分析**：记录每日饮食，自动分析营养摄入与血糖影响。
- **健康知识科普**：提供糖尿病饮食相关的科学知识和注意事项。
